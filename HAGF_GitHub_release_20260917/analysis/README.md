# Analysis scripts

This directory contains the post-processing and reviewer-analysis scripts used
with saved HAGF runs. They do not replace model training and generally expect
the prediction tables, configurations, masks, or checkpoints produced by
`hagf.runner`.

## General-purpose command-line summaries

- `audit_existing_predictions.py`: audit binary held-out prediction files.
- `audit_existing_tissue.py`: audit multiclass tissue-of-origin predictions.
- `summarize_run.py`: summarize a repeated cross-validation run.
- `summarize_independent.py`: summarize independent-cohort evaluation.
- `compare_component_ablation.py`: compare architectural ablations.
- `compare_hidden_full.py` and `summarize_hidden_pilot.py`: summarize
  hidden-dimension sensitivity.
- `summarize_tuning_validation.py`: summarize validation-only model selection.
- `figure4_fdr.py`: apply multiplicity control to prespecified score contrasts.
- `edm_enrichment.py`: test motif enrichment with adjusted P values.
- `pathway_evidence_audit.py`: audit pathway-analysis evidence tables.
- `plot_hra_original_auc_audit.py` and `plot_prj_full_summary.py`: recreate AUC
  audits from archived predictions.

Run a script with `--help` to inspect its required inputs.

## Project-layout-dependent analyses

The following scripts reproduce analyses that combine several archived run
directories or manuscript-specific resources:

- `build_modality_occlusion_figure.py`
- `build_reviewer4_lomo_detection.py`
- `individual_attribution.py`
- `organ_knowledge_consistency.py`
- `plot_feature_order_adjusted.py`

Set `HAGF_PROJECT_ROOT` to a project tree containing the expected
`revision_workspace/` and, where applicable, `Methylation/SUBJECT/` resources:

```bash
export HAGF_PROJECT_ROOT=/path/to/full/HAGF/project
python analysis/individual_attribution.py
```

Those archived predictions, feature matrices, checkpoints, and KEGG mapping
tables are intentionally excluded from this public source package. Some
analyses therefore require the authors' prepared resources or equivalent files
generated by the user.
